# Метрики пилота

Для реального пилота команда определила следующие метрики:

- **Activation** - дошёл до афиши / создал профиль;
- **Event Intent** - добавил хотя бы одно событие в планы;
- **Company Search** - запустил поиск компании;
- **Candidate -> Like** - выбрал «Пойти вместе»;
- **Match Rate** - получил взаимный мэтч;
- **Contact Exchange** - после мэтча отправлен подтверждённый контакт;
- **Confirmed Joint Outing** - подтверждён реальный совместный поход;
- **Time to Match** - время от запуска поиска до мэтча;
- **Repeat Use** - повторный план или поиск компании.

Важно: эти метрики были определены для будущего пилота; массовый пилот и retention в рамках хакатона не измерялись.
