# Research summary

## Метод

- разведочный онлайн-опрос: **82 ответа**;
- период: 21-22.09.2026;
- 3 качественных интервью;
- выборка нерепрезентативна, результаты использовались для проверки проблемы и уточнения MVP, а не для оценки рынка.

## Ключевые результаты

| Наблюдение | Результат |
|---|---:|
| Не пошли на понравившееся событие из-за отсутствия компании хотя бы 1 раз за 3 месяца | 51 / 82 = **62,2%** |
| Сталкивались с этим неоднократно | 34 / 82 = **41,5%** |
| Обычно ищут человека в чатах / сообществах | 6 / 82 = **7,3%** |
| Интерес к идее сервиса: оценка 4-5 из 5 | 43 / 82 = **52,4%** |
| Среди респондентов 18+: сталкивались с проблемой хотя бы раз | 38 / 62 = **61,3%** |

## Основные барьеры выбора досуга

Чаще всего отмечались:

1. цена - 36 ответов;
2. неудобное время - 33;
3. трудно найти события под интересы - 31;
4. неудобное место - 22;
5. информация разбросана по разным сервисам - 20;
6. не с кем пойти - 19.

## Что важно знать о потенциальной компании

Чаще всего респонденты выбирали:

- описание о себе - 59;
- общие интересы - 58;
- фото - 53;
- возраст - 52;
- имя - 45;
- подтверждённый профиль - 41;
- конкретное событие - 40.

## Вывод для продукта

Проблема отсутствия компании существует у заметной части опрошенных, но не у всех. Поэтому MVP сфокусирован на пользователе, который уже выбрал конкретное событие, не хочет идти один и готов рассмотреть нового человека при наличии понятного контекста и взаимного выбора.
